# ApnaTrip Backend API

Express + TypeScript backend server for ApnaTrip.

## Getting Started

```bash
npm install
npm run dev
```

## Structure
- `src/api` - API endpoints
- `src/controllers` - Route logic
- `src/routes` - Route definitions
- `src/middleware` - Middlewares (error handling, auth)
- `src/config` - Environment configuration
- `src/services` - Core business services
- `src/models` - Data models & schemas
