# ApnaTrip Frontend

React + TypeScript + Vite + Tailwind CSS + Framer Motion authentication & travel UI.

## Getting Started

```bash
npm install
npm run dev
```

## Routes
- `/` - Animated Splash Screen
- `/onboarding` - 3-step Onboarding Carousel
- `/login` - Auth Login Page
- `/signup` - Auth Signup Page
- `/profile-setup` - Profile Setup Page
